MỤC TIÊU
Người dùng dán link YouTube → lấy transcript có timestamp (ưu tiên phụ đề có sẵn của
YouTube, fallback Whisper) → sửa → nhờ Gemini chuyển thể sang nhiều ngôn ngữ → lưu thành
nhiều file input để pipeline cũ chạy tiếp. Ngôn ngữ đích ghi bằng hậu tố tên file
(_en, _es...) để core/languages.detect_suffix_language() tự nhận.

PHẦN A — core/subtitles.py (file mới, dùng chung cho Phase 3)
  @dataclass Cue: index:int, start:float, end:float, text:str
  format_timestamp(seconds, sep=",") -> "HH:MM:SS,mmm"     (SRT)
  parse_timestamp(text) -> float                            (nhận cả "," và ".")
  parse_srt(text: str) -> List[Cue]
    - chịu được BOM, CRLF, block thiếu index, text nhiều dòng, dòng rác
    - bỏ cue rỗng; end < start thì đảo; lỗi từng block thì skip + log warning
  parse_vtt(text: str) -> List[Cue]
    - bỏ header WEBVTT, NOTE, STYLE; timestamp dạng "00:00:01.000 --> 00:00:04.500"
      và dạng ngắn "00:01.000"; bỏ phần cue settings sau timestamp
    - gộp cue trùng thời gian liên tiếp (YouTube auto-sub hay lặp dòng)
  write_srt(cues: List[Cue], path) -> Path  (atomic: ghi file .tmp rồi os.replace)
  cues_to_text(cues) -> str   # nối text thành đoạn văn, giữ xuống dòng giữa cue
  text_to_cues(text, total_seconds=0.0) -> List[Cue]
    # chia theo đoạn/câu bằng core/text_processor.split_sentences + split_for_tts,
    # timing chia đều theo độ dài ký tự (dùng khi import TXT không có timestamp)

TIÊU CHÍ NGHIỆM THU
- Dán link có phụ đề → transcript hiện trong <10s (không tải video); dán link không có
  phụ đề → tự chuyển Whisper và báo tiến trình rõ.
- Sửa text 1 cue trong bảng → lưu SRT phản ánh đúng thay đổi.
- Chọn 3 ngôn ngữ + Chuyển thể → 3 file input/<base>_xx.txt xuất hiện; tab Dự án quét
  lại thấy 3 item với ngôn ngữ đúng (VI/EN/ES...).
- Huỷ giữa chừng không treo app; đóng app khi đang chạy có cảnh báo.
- Không có API key Gemini: nút Chuyển thể báo lỗi tiếng Việt rõ, không crash.
