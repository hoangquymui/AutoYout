Repo: D:\mui\f375\AutoYout. Đọc prompts/00_context.txt trước.
Phụ thuộc mềm: Phase 2 (script/*.json để lấy transcript). Không bắt buộc Phase 3.

MỤC TIÊU
Tab YouTube hiện tại (kênh, lịch, metadata) tách thành 2 sub-tab:
  - "Đăng tải": giữ NGUYÊN toàn bộ chức năng hiện có.
  - "Hình thu nhỏ": từ transcript của item → gợi ý tiêu đề ngắn → tạo ảnh nền (AI hoặc
    frame video) → ghép theo template chữ đậm kiểu "story channel" → lưu
    thumbs/<base>.jpg và gắn vào metadata item để uploader dùng.

PHẦN A — core/thumbnail.py (file mới)
  # ── Tiêu đề ────────────────────────────────────────────────────────────────
  parse_title_suggestions(raw: str, limit: int = 5) -> List[str]
    * chấp nhận JSON array, JSON trong ```json fence, hoặc mỗi dòng 1 tiêu đề
    * lọc trùng, cắt khoảng trắng, bỏ dòng rỗng, tối đa `limit`
  suggest_titles(transcript: str, api_key: str, model: str = "gemini-2.0-flash",
                 language: str = "vi", generate_fn=None) -> List[str]
    * prompt (tiếng Việt): "Dựa trên nội dung sau, viết 5 tiêu đề YouTube dạng hook tò mò
      cho kênh kể chuyện. Mỗi tiêu đề <= 60 ký tự, viết HOA các từ khoá mạnh, không bịa
      sự kiện không có trong nội dung, không emoji. Chỉ trả về JSON array chuỗi."
    * generate_fn inject được khi test; mặc định core.ai_client.gemini_generate

  # ── Prompt ảnh ─────────────────────────────────────────────────────────────
  build_image_prompt(title: str, transcript_excerpt: str, style: str,
                     template_id: str) -> str
    * mô tả bối cảnh từ transcript (600 ký tự), nhân vật/hành động chính
    * luôn nối thêm: "cinematic, dramatic lighting, high detail, 16:9, photo-realistic,
      no text, no watermark, no real person likeness"
    * với template "drama_left": thêm "main subject on the RIGHT side of frame,
      negative space on the LEFT for text"

  # ── Sinh ảnh nền (3 provider) ──────────────────────────────────────────────
  generate_image(provider, prompt, out_path, *, api_key="", model="",
                 width=1280, height=720, seed=None) -> Path
    - "imagen": dùng core.ai_images.ImagenProvider (đã có), lưu PNG/JPG
    - "pollinations": GET https://image.pollinations.ai/prompt/{urlencoded_prompt}
      ?width=1280&height=720&nologo=true(&seed=N) bằng urllib, timeout 120s,
      header User-Agent giống input_pipeline; kiểm tra content-type image/* và size > 10KB
    - "frame": ffmpeg -ss <giây> -i <video> -frames:v 1 -q:v 2 <out.jpg>
      (lấy video từ manager.video_for_item(item).path nếu có)
    - lỗi mạng → raise RuntimeError message tiếng Việt, không nuốt lỗi

  # ── Template + render (Pillow) ─────────────────────────────────────────────
  @dataclass ThumbTemplate:
    id: str; name: str; description: str
    text_box: tuple          # (x, y, w, h) trên 1280x720
    align: str               # "left" | "center"
    gradient: str            # "left" | "bottom" | "none"
    max_font: int; min_font: int
    line_height: float       # 1.02 - 1.1
    stroke_ratio: float      # 0.08 - 0.12 (theo cỡ chữ)
  TEMPLATES: Dict[str, ThumbTemplate] gồm 4 preset:
    "drama_left"  — lấy cảm hứng từ ảnh mẫu: chữ khối trái (x=48,y=48,w=620,h=624),
                    align left, gradient left, font 96→64, line_height 1.03, stroke 0.10
    "top_center"  — chữ trên đầu, gradient bottom, align center
    "split_50"    — nửa trái chữ, nửa phải ảnh, gradient left
    "quote_card"  — nền tối, chữ giữa, gradient bottom

  wrap_title_lines(draw, text, font, max_width) -> List[str]   # ngắt theo từ, IN HOA
  autosize_font(text, box_w, box_h, max_font, min_font, line_height, font_path) -> ImageFont
  render_thumbnail(bg_path, title, highlights, template_id, palette,
                   out_path, size=(1280,720)) -> Path
    * highlights: List[Tuple[word, "green"|"red"]] — tô màu theo từ (không phân biệt hoa
      thường, khớp nguyên từ)
    * nền: cover-crop về 16:9; gradient đen mờ (alpha 210 → 0) phủ vùng chữ
    * chữ trắng đậm, viền đen (stroke_width = font_size * stroke_ratio), shadow lệch 4px
    * palette mặc định: white "#FFFFFF", green "#3BFF35", red "#FF3B30"
    * font: tìm theo thứ tự ui/assets/fonts/{Anton,Montserrat-ExtraBold}.ttf →
      C:\Windows\Fonts\arialbd.ttf → seguisb.ttf → ImageFont.load_default()
    * lưu JPEG quality 90 (nếu out_path .jpg) hoặc PNG
  Bắt buộc: hàm render phải chạy < 500ms và KHÔNG gọi mạng.

  # ── Gắn thumbnail vào item ─────────────────────────────────────────────────
  attach_thumbnail(manager, base, image_path) -> Path
    * copy ảnh vào manager.thumbs_dir/<base>.jpg (giữ nguyên nếu đã nằm đó)
    * merge vào input/<base>.json: "thumbnail_path": "<đường dẫn TUYỆT ĐỐI>"
      (normalize_metadata chỉ resolve tương đối theo input/ rồi assets/, nên dùng
      tuyệt đối cho chắc)
    * cập nhật item.metadata["thumbnail_path"], manager.save_state()
    * KHÔNG đổi các key JSON khác của item

PHẦN B — ui/tab_thumbnail.py (file mới)
  class ThumbnailPanel(QWidget), signals: thumbnail_saved = Signal(str)  # base
  API: set_project(manager), apply_theme(), load_from(settings), apply_to(settings)

  Bố cục 2 cột:
  Cột trái (điều khiển):
    1) Combo "File trong project" (hiển thị item.display_name, data=base) + nút refresh
    2) QPlainTextEdit "Tiêu đề" (3-6 dòng, mỗi dòng 1 dòng thumbnail, mặc định lấy
       metadata title); nút "Gợi ý tiêu đề" (icon "zap", QThread TitleWorker) đổ kết quả
       vào QListWidget để chọn 1 → điền vào ô tiêu đề
    3) Tô màu từ khoá: QLineEdit "Từ cần tô" + combo màu (Xanh/Đỏ) + nút "Thêm";
       QListWidget các từ đã chọn (xanh/đỏ hiển thị icon màu) + nút "Bỏ"
    4) Prompt ảnh: QPlainTextEdit (auto-fill từ build_image_prompt khi đổi item/tiêu đề),
       combo provider (Imagen / Pollinations (free) / Frame từ video), ô "Style",
       nút "Tạo ảnh nền" (ImageWorker QThread, progress label, Huỷ)
    5) Template: QListWidget 4 preset kèm mô tả ngắn; combo palette; spin cỡ chữ;
       checkbox "Xem trước tự động"
  Cột phải:
    - QLabel preview 16:9 (hiển thị bản 640x360 scale từ 1280x720; giữ QPixmap gốc)
    - Nút "Xem trước" (render Pillow → QPixmap), "Lưu thumbnail" (primaryButton),
      "Mở file"
  Luồng: chọn item → tự load title từ metadata + transcript (script/<base>.json nếu có)
  → gợi ý/sửa tiêu đề → tạo ảnh → chọn template/tô màu → preview → Lưu.
  Lưu xong gọi attach_thumbnail + emit thumbnail_saved(base).

  Lưu ý theme: preview phải cập nhật khi đổi sáng/tối (apply_theme chỉ đổi nền khung,
  không đổi ảnh render).

TIÊU CHÍ NGHIỆM THU
- Mở sub-tab Hình thu nhỏ, chọn item → tiêu đề tự điền từ metadata.
- Bấm "Gợi ý tiêu đề" (có key Gemini) → 5 gợi ý, chọn 1 điền vào ô tiêu đề.
- Provider Pollinations (không key) tạo được ảnh 1280x720; provider Frame lấy được frame
  từ video đã render.
- Preview hiển thị chữ in hoa, viền đen, từ khoá xanh/đỏ, ảnh bên phải (drama_left).
- Lưu → thumbs/<base>.jpg tồn tại; input/<base>.json có thumbnail_path; uploader dùng
  đúng thumbnail (kiểm tra bằng test đọc metadata).
- Đổi theme sáng/tối không làm vỡ preview; tab Đăng tải hoạt động y như trước.
- Không có mạng/key: báo lỗi tiếng Việt, không crash; render vẫn chạy với ảnh nền có sẵn.
