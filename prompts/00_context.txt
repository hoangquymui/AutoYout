=== APP LÀ GÌ ===
AutoYout là app desktop Python 3.11 + PySide6, pipeline:
  Input (YouTube/web/media → .txt) → TTS (H2MTTS cho tiếng Việt, edge-tts cho ngôn ngữ khác)
  → Video (FFmpeg: ảnh/video nền + audio + phụ đề) → Upload YouTube (OAuth2 hoặc Playwright).
Quản lý theo "project folder": mỗi project có input/, audio/, video/, assets/ và file
project_state.json (lưu trạng thái từng item + video job).

Mục tiêu nâng cấp (đang triển khai theo 4 phase):
  1. Project skeleton: tự tạo đủ thư mục (input, script, audio, video, thumbs, assets,
     downloads, output) + nút "Tạo Project mới".
  2. Tab Kịch bản: YouTube URL → transcript có timestamp → Gemini chuyển thể đa ngôn ngữ
     → nhiều file input (_en, _es...).
  3. Tab Giọng đọc đổi thành Lồng tiếng: bảng cue SRT (Id/Timing/Content/Voice/Status),
     TTS từng cue, Join MP3 + xuất SRT.
  4. Tab YouTube tách thành 2 sub-tab: "Đăng tải" (giữ nguyên) và "Hình thu nhỏ"
     (gợi ý tiêu đề, prompt tạo ảnh, template thumbnail 1280x720).

=== LUỒNG DỮ LIỆU QUAN TRỌNG ===
- ProjectManager.scan() chỉ nhận file .txt/.json trong input/ và ghép theo stem
  (name.txt + name.json). Ngôn ngữ item lấy theo thứ tự: metadata > hậu tố tên file
  (_en, _es) > ngôn ngữ mặc định của project.
- PipelineWorker._stage_tts() tách item theo ngôn ngữ: vi → TTSEngine, khác → EdgeTTSEngine.
- normalize_metadata() đọc "thumbnail_path" trong JSON item; đường dẫn tương đối được
  resolve theo thư mục chứa JSON rồi fallback assets/. Uploader dùng metadata này.
- Naming output chuẩn: input/<base>.txt, audio/<base>.mp3, video/<base>.mp4.
